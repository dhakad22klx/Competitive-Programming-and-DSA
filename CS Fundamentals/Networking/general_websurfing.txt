1. An Internet Protocol (IP) address is a unique numerical identifier for every device or network that connects to the internet. Typically assigned by an internet service provider (ISP), an IP address is an online device address used for communicating across the internet.

2. In computer networking, a proxy server is a server application that acts as an intermediary between a client requesting a resource and the server providing that resource.[1] It improves privacy, security, and performance in the process.

3. In product development, an end user (sometimes end-user) is a person who ultimately uses or is intended to ultimately use a product.

4. ARP stand for Address Resolution Protocol are the way to translate IP address to machine address (MAC Address) or the way to find out which machine has the IP address.
